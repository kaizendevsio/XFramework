# Payment Gateway System

This module provides abstractions and implementations for various payment gateways with support for cash in (including callback-based flows) and cash out operations.

## Features

- Abstract payment gateway provider interface
- Support for cash in and cash out operations
- Support for callback/webhook based payment flows
- Merchant wallet balance management
- Extensible design for adding new payment providers
