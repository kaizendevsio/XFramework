# Partial Class Override Pattern - XFramework

## Overview

XFramework uses source generators to create CRUD services automatically, leveraging C#'s partial class feature to enable safe customization. This pattern allows developers to extend generated code without modifying it directly, maintaining a clean separation between generated and custom logic.

## How Source Generators Work

### The Generation Process

1. **Developer marks entity with attribute:**
```csharp
[GenerateEndpoints(Type = GenerationType.Service, Actions = CrudAction.All)]
public class Product
{
    public Guid Id { get; set; }
    public string Name { get; set; }
    public decimal Price { get; set; }
    // ...
}
```

2. **Source generator runs at compile time:**
   - Analyzes the `Product` class
   - Generates `IProductService` interface
   - Generates `ProductService` partial class implementation
   - Outputs to `obj/` directory

3. **Generated code becomes part of compilation:**
   - Available via IntelliSense
   - No runtime reflection needed
   - Type-safe

### What Gets Generated

The [`EntityServiceGenerator`](../../src/SourceGenerators/XFramework.SourceGenerators/EntityServiceGenerator.cs) creates:

**Interface** (`IProductService`):
```csharp
public interface IProductService
{
    Task<Result<Product>> CreateAsync(CreateProductRequest request, CancellationToken ct = default);
    Task<Result<Product>> GetByIdAsync(Guid id, CancellationToken ct = default);
    Task<Result<List<Product>>> GetListAsync(GetProductListRequest request, CancellationToken ct = default);
    Task<Result<Product>> UpdateAsync(Guid id, UpdateProductRequest request, CancellationToken ct = default);
    Task<Result<bool>> DeleteAsync(Guid id, CancellationToken ct = default);
}
```

**Implementation** (`ProductService.g.cs`):
```csharp
// <auto-generated/>
public partial class ProductService : IProductService

    {
        _dbContext = dbContext;

    }

    public virtual async Task<Result<Product>> CreateAsync(
        CreateProductRequest request, 
        CancellationToken ct = default)
    {
        // Generated CRUD logic
    }

    public virtual async Task<Result<Product>> GetByIdAsync(
        Guid id, 
        CancellationToken ct = default)
    {
        // Generated CRUD logic
    }

    // ... other generated methods

```

**Key Points:**
- ✅ Methods are `virtual` - can be overridden
- ✅ Class is `partial` - can be extended
- ✅ Dependencies injected via constructor
- ✅ Returns `Result<T>` pattern
- ✅ Includes logging and caching

## Extending Generated Services

### Pattern 1: Add Custom Methods

Create a manual partial class to add new methods:

```csharp
// File: ProductService.cs (manual)
namespace YourModule.Core.Services;

public partial class ProductService
{
    /// <summary>
    /// Custom method: Get products by category with stock information
    /// </summary>
    public async Task<Result<List<ProductWithStock>>> GetByCategoryWithStockAsync(
        Guid categoryId,
        CancellationToken ct = default)
    {
        try
        {
            var products = await _dbContext.Set<Product>()
                .AsNoTracking()
                .Where(p => p.CategoryId == categoryId && !p.IsDeleted)
                .Select(p => new ProductWithStock
                {
                    Id = p.Id,
                    Name = p.Name,
                    Price = p.Price,
                    StockQuantity = p.Inventory != null ? p.Inventory.Quantity : 0
                })
                .ToListAsync(ct);

            return Result<List<ProductWithStock>>.Success(products);
        }
        catch (Exception ex)
        {
            _logger.LogError(ex, "Error retrieving products for category {CategoryId}", categoryId);
            return Result<List<ProductWithStock>>.Failure("Failed to retrieve products", 500);
        }
    }

    /// <summary>
    /// Custom method: Bulk import products
    /// </summary>
    public async Task<Result<BulkImportResult>> BulkImportAsync(
        List<CreateProductRequest> requests,
        CancellationToken ct = default)
    {
        using var transaction = await _dbContext.Database.BeginTransactionAsync(ct);
        
        try
        {
            var imported = new List<Product>();
            var errors = new List<string>();

            foreach (var request in requests)
            {
                var result = await CreateAsync(request, ct);
                if (result.IsSuccess && result.Data != null)
                {
                    imported.Add(result.Data);
                }
                else
                {
                    errors.Add($"SKU {request.SKU}: {result.Message}");
                }
            }

            await transaction.CommitAsync(ct);

            var bulkResult = new BulkImportResult
            {
                TotalProcessed = requests.Count,
                SuccessCount = imported.Count,
                FailureCount = errors.Count,
                Errors = errors
            };

            _logger.LogInformation(
                "Bulk import completed: {Success}/{Total} successful",
                imported.Count, requests.Count);

            return Result<BulkImportResult>.Success(bulkResult);
        }
        catch (Exception ex)
        {
            await transaction.RollbackAsync(ct);
            _logger.LogError(ex, "Bulk import failed");
            return Result<BulkImportResult>.Failure("Bulk import failed", 500);
        }
    }
}
```

## Virtual Method Overrides

### Pattern 1: Override with Pre-validation

Add validation before calling base implementation:

```csharp
// File: ProductService.cs (manual)
public partial class ProductService
{
    public override async Task<Result<Product>> CreateAsync(
        CreateProductRequest request,
        CancellationToken ct = default)
    {
        // Custom validation
        if (request.Price <= 0)
        {
            _logger.ValidationFailed("CreateProduct", "Price must be positive");
            return Result<Product>.Failure("Price must be positive", 400);
        }

        if (string.IsNullOrWhiteSpace(request.SKU))
        {
            return Result<Product>.Failure("SKU is required", 400);
        }

        // Check business rules
        if (request.Price > 10000 && !await IsApprovedForHighValueProductsAsync(ct))
        {
            return Result<Product>.Forbidden(
                "You don't have permission to create high-value products");
        }

        // Call base implementation
        var result = await base.CreateAsync(request, ct);

        // Post-creation logic
        if (result.IsSuccess && result.Data != null)
        {
            await _notificationService.NotifyNewProductAsync(result.Data, ct);
        }

        return result;
    }

    private async Task<bool> IsApprovedForHighValueProductsAsync(CancellationToken ct)
    {
        // Check user permissions
        return true; // Simplified
    }
}
```

### Pattern 2: Override with Custom Caching Strategy

```csharp
public partial class ProductService
{
    public override async Task<Result<Product>> GetByIdAsync(
        Guid id,
        CancellationToken ct = default)
    {
        // Custom cache key strategy with versioning
        var cacheKey = $"product:v2:{id}";
        
        // Try cache first with custom duration
        var cached = await _cacheService.GetAsync<Product>(cacheKey, ct);
        if (cached.IsSuccess && cached.Data != null)
        {
            _logger.CacheHit(cacheKey);
            return Result<Product>.Success(cached.Data);
        }

        _logger.CacheMiss(cacheKey);

        // Use base implementation to fetch from database
        var result = await base.GetByIdAsync(id, ct);

        // Custom cache logic
        if (result.IsSuccess && result.Data != null)
        {
            // Cache for 10 minutes instead of default 5
            await _cacheService.SetAsync(
                cacheKey,
                result.Data,
                absoluteExpiration: TimeSpan.FromMinutes(10),
                cancellationToken: ct);
        }

        return result;
    }
}
```

### Pattern 3: Complete Replacement

Replace entire method when base implementation isn't suitable:

```csharp
public partial class ProductService
{
    public override async Task<Result<Product>> UpdateAsync(
        Guid id,
        UpdateProductRequest request,
        CancellationToken ct = default)
    {
        // Completely custom implementation - not calling base
        using var activity = ActivitySources.Product.StartActivity("Product.Update");
        activity?.SetTag("product.id", id);

        try
        {
            // Fetch with tracking for update
            var product = await _dbContext.Set<Product>()
                .Include(p => p.Inventory) // Include related data
                .FirstOrDefaultAsync(p => p.Id == id && !p.IsDeleted, ct);

            if (product == null)
            {
                return Result<Product>.NotFound($"Product {id} not found");
            }

            // Track changes for audit
            var originalPrice = product.Price;

            // Update properties
            product.Name = request.Name;
            product.Price = request.Price;
            product.Description = request.Description;

            // Business rule: Adjust inventory if price changed significantly
            if (Math.Abs(product.Price - originalPrice) > originalPrice * 0.1m)
            {
                // More than 10% price change
                await RecalculateInventoryValueAsync(product, ct);
            }

            await _dbContext.SaveChangesAsync(ct);

            // Invalidate all product-related caches
            await _cacheService.RemoveAsync($"product:{id}", ct);
            await _cacheService.RemoveByPrefixAsync("product:list:", ct);

            _logger.EntityUpdated("Product", id);
            activity?.SetStatus(ActivityStatusCode.Ok);

            return Result<Product>.Success(product);
        }
        catch (DbUpdateConcurrencyException)
        {
            _logger.ConcurrencyConflict("Product", id);
            return Result<Product>.Conflict("The product was modified by another user");
        }
        catch (Exception ex)
        {
            activity?.SetStatus(ActivityStatusCode.Error, ex.Message);
            _logger.OperationFailed("UpdateProduct", "Product", id, ex.Message, ex);
            return Result<Product>.Failure("Failed to update product", 500);
        }
    }

    private async Task RecalculateInventoryValueAsync(Product product, CancellationToken ct)
    {
        if (product.Inventory != null)
        {
            product.Inventory.TotalValue = product.Price * product.Inventory.Quantity;
            _logger.LogInformation(
                "Recalculated inventory value for product {ProductId}: {Value}",
                product.Id, product.Inventory.TotalValue);
        }
    }
}
```

## Best Practices

### 1. Don't Modify Generated Files

```csharp
// ❌ NEVER DO THIS
// File: ProductService.g.cs
public partial class ProductService : IProductService
{
    // Adding code here will be overwritten on next build!
}
```

```csharp
// ✅ ALWAYS DO THIS
// File: ProductService.cs
public partial class ProductService
{
    // Add your custom code here
}
```

### 2. Call Base When Possible

```csharp
// ✅ Good: Reuse base logic
public override async Task<Result<Product>> CreateAsync(
    CreateProductRequest request,
    CancellationToken ct = default)
{
    // Pre-validation
    if (!await ValidateCustomRulesAsync(request))
        return Result<Product>.Failure("Validation failed", 400);

    // Leverage base implementation
    var result = await base.CreateAsync(request, ct);

    // Post-processing
    if (result.IsSuccess)
        await SendNotificationAsync(result.Data);

    return result;
}
```

### 3. Use Descriptive Names for Custom Methods

```csharp
// ❌ Bad: Generic name
public async Task<Result<Product>> Get(Guid categoryId) { }

// ✅ Good: Descriptive name
public async Task<Result<List<Product>>> GetActiveByCategoryAsync(
    Guid categoryId, 
    CancellationToken ct = default) { }
```

### 4. Maintain Consistent Patterns

```csharp
// ✅ Good: Follow same patterns as generated code
public async Task<Result<ProductAnalytics>> GetAnalyticsAsync(
    Guid productId,
    CancellationToken ct = default)  // Always include CancellationToken
{
    try  // Always use try-catch
    {
        // Logic here
        _logger.LogInformation(/* ... */);  // Always log
        return Result<ProductAnalytics>.Success(analytics);
    }
    catch (Exception ex)
    {
        _logger.LogError(ex, /* ... */);
        return Result<ProductAnalytics>.Failure("Failed to get analytics", 500);
    }
}
```

### 5. Document Custom Logic

```csharp

public partial class WalletService
{
    // Additional dependencies injected via constructor
    private readonly ITenantService _tenantService;
    private readonly IIdentityServerServiceWrapper _identityServerService;
    private readonly IHelperService _helperService;

    // Custom complex operations
    public async Task<Result> IncrementBalanceAsync(
        IncrementWalletRequest request,
        CancellationToken cancellationToken = default)
    {
        using var activity = ActivitySources.Wallet.StartActivity("Wallet.IncrementBalance");
        activity?.SetTag("wallet.id", request.WalletId);
        activity?.SetTag("wallet.amount", request.TotalAmount);

        try
        {
            // Complex business logic
            var wallet = await FetchOrCreateWalletAsync(request, cancellationToken);
            
            // Validate business rules
            if (wallet.MinTransferRule.HasValue && 
                request.TotalAmount < wallet.MinTransferRule.Value)
            {
                _logger.BusinessRuleViolation("IncrementWallet", 
                    $"Amount below minimum {wallet.MinTransferRule.Value}");
                return Result.Failure(
                    $"Amount must be at least {wallet.MinTransferRule.Value}", 400);
            }

            // Update balances
            if (request.OnHold)
                wallet.CreditOnHoldBalance += request.TotalAmount;
            else
            {
                wallet.Balance += request.TotalAmount;
                wallet.TransferableBalance += request.TotalAmount;
            }

            // Create transaction record
            var transaction = new WalletTransaction
            {
                WalletId = wallet.Id,
                Amount = request.TotalAmount,
                TransactionType = TransactionType.Credit,
                // ... other properties
            };

            _dbContext.Set<WalletTransaction>().Add(transaction);
            await _dbContext.SaveChangesAsync(cancellationToken);

            // Metrics and logging
            XFrameworkMetrics.WalletIncrements.Add(1);
            _logger.WalletIncremented(wallet.Id, request.TotalAmount, 
                "Primary", wallet.Balance);

            return Result.Success();
        }
        catch (DbUpdateConcurrencyException)
        {
            _logger.ConcurrencyConflict("Wallet", request.WalletId);
            return Result.Failure("Concurrency conflict occurred", 409);
        }
        catch (Exception ex)
        {
            _logger.OperationFailed("IncrementWallet", "Wallet", 
                request.WalletId, ex.Message, ex);
            return Result.Failure("An error occurred", 500);
        }
    }

    public async Task<Result> TransferAsync(
        TransferWalletRequest request,
        CancellationToken cancellationToken = default)
    {

        // See full implementation in WalletService.cs
    }

    // Private helper methods

        IncrementWalletRequest request,
        CancellationToken ct)
    {

    }
}
```

## Common Patterns

### Pattern 1: Inject Additional Dependencies

```csharp
public partial class ProductService
{
    // These are already injected by generated code:
    // - DbContext _dbContext
    // - ICacheService _cacheService
    // - ILogger<ProductService> _logger

    // Add more via another constructor
    private readonly IEmailService _emailService;
    private readonly IInventoryService _inventoryService;

    public ProductService(
        DbContext dbContext,
        ICacheService cacheService,
        ILogger<ProductService> logger,
        IEmailService emailService,         // Additional
        IInventoryService inventoryService) // Additional
        : this(dbContext, cacheService, logger) // Call generated constructor
    {
        _emailService = emailService;
        _inventoryService = inventoryService;
    }
}
```

### Pattern 2: Add Private Helper Methods

```csharp
public partial class ProductService
{
    private async Task<bool> ValidateStockAvailabilityAsync(
        Guid productId,
        int quantity,
        CancellationToken ct)
    {
        var inventory = await _dbContext.Set<Inventory>()
            .FirstOrDefaultAsync(i => i.ProductId == productId, ct);

        return inventory != null && inventory.Quantity >= quantity;
    }

    private string GenerateSKU(string category, string name)
    {
        var prefix = category.Substring(0, 3).ToUpper();
        var hash = name.GetHashCode().ToString("X");
        return $"{prefix}-{hash}";
    }
}
```

### Pattern 3: Add Computed Properties

```csharp
public partial class ProductService
{
    private bool IsHighValueProduct => // Cannot add instance properties to partial class
                                        // Use methods instead

    private decimal GetDiscountThreshold()
    {
        return 1000m; // Can inject from configuration
    }

    public async Task<Result<bool>> IsEligibleForDiscountAsync(
        Guid productId,
        CancellationToken ct = default)
    {
        var result = await GetByIdAsync(productId, ct);
        if (!result.IsSuccess || result.Data == null)
            return Result<bool>.Failure("Product not found", 404);

        var isEligible = result.Data.Price >= GetDiscountThreshold();
        return Result<bool>.Success(isEligible);
    }
}
```
