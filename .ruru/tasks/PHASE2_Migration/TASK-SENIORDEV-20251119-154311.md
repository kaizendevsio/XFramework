# Task: Migrate Inventario Module to VSA (Phase 2)

## Description

Migrate the Inventario module from generator-based endpoints to manual Vertical Slice Architecture implementation. This serves as the **proof of concept** for the VSA migration pattern that will be applied to all other modules.

**Context:**
- This is the XFramework VSA Migration project
- Phase 1 (Foundation) is 100% complete
- Inventario currently uses `GenerateEndpoints` attribute with source generator
- We'll create a proper VSA implementation with Product as the main entity
- This migration demonstrates the pattern for all future module migrations

**Current Implementation:**
- Endpoints generated via `GenerateEndpointsAttribute`
- Minimal business logic in Inventario.Core
- Product entity with relationships (Category, Variations, Transactions)

**Target Implementation:**
- Manual VSA features in `Inventario.Api/Features/Products/`
- ProductService with full CRUD operations using Result<T>
- Manual endpoints with caching, validation, error handling
- Performance optimizations (compiled queries, projections)

## Technical Notes

**Service Implementation Pattern:**
```csharp
public class ProductService
{
    private readonly DbContext _dbContext;
    private readonly ICacheService _cacheService;
    private readonly ILogger<ProductService> _logger;

    public ProductService(DbContext dbContext, ICacheService cacheService, ILogger<ProductService> logger)
    {
        _dbContext = dbContext;
        _cacheService = cacheService;
        _logger = logger;
    }

    public async Task<Result<Product>> GetByIdAsync(Guid id, CancellationToken ct = default)
    {
        try
        {
            var cacheKey = $"products:{id}";
            
            // Try cache first (using Phase 1.3 HybridCacheService)
            var cached = await _cacheService.GetAsync<Product>(cacheKey, ct);
            if (cached.IsSuccess && cached.Data != null)
            {
                _logger.LogDebug("Product {ProductId} retrieved from cache", id);
                return Result<Product>.Success(cached.Data);
            }

            // Query database (NoTracking default from Phase 1.5)
            var product = await _dbContext.Set<Product>()
                .Include(p => p.Category)
                .FirstOrDefaultAsync(p => p.Id == id && !p.IsDeleted, ct);

            if (product == null)
            {
                _logger.LogWarning("Product {ProductId} not found", id);
                return Result<Product>.NotFound($"Product with ID {id} not found");
            }

            // Cache the result
            await _cacheService.SetAsync(cacheKey, product, 
                absoluteExpiration: TimeSpan.FromMinutes(10), ct);

            _logger.LogInformation("Product {ProductId} retrieved successfully", id);
            return Result<Product>.Success(product);
        }
        catch (Exception ex)
        {
            _logger.LogError(ex, "Error retrieving product {ProductId}", id);
            return Result<Product>.Failure("An error occurred retrieving the product", 500);
        }
    }
}
```

**Endpoint Implementation Pattern:**
```csharp
public static class GetProductEndpoint
{
    public static IEndpointRouteBuilder MapGetProduct(this IEndpointRouteBuilder app)
    {
        app.MapGet("/api/products/{id:guid}", GetProduct)
            .CacheOutput("ProductsPolicy") // From Phase 1.4
            .WithName("GetProduct")
            .WithTags("Products")
            .WithOpenApi();
            
        return app;
    }

    private static async Task<IResult> GetProduct(
        Guid id,
        ProductService productService,
        CancellationToken ct)
    {
        var result = await productService.GetByIdAsync(id, ct);
        
        return result.Match(
            onSuccess: product => Results.Ok(product),
            onFailure: error => error.StatusCode switch
            {
                404 => Results.NotFound(new { error.Message }),
                _ => Results.Problem(error.Message, statusCode: error.StatusCode)
            });
    }
}
```

**Cache Invalidation Pattern:**
```csharp
public async Task<Result<Product>> UpdateAsync(Guid id, UpdateProductRequest request, CancellationToken ct)
{
    try
    {
        var product = await _dbContext.Set<Product>()
            .AsTracking() // Explicit tracking for update
            .FirstOrDefaultAsync(p => p.Id == id && !p.IsDeleted, ct);

        if (product == null)
            return Result<Product>.NotFound($"Product with ID {id} not found");

        // Update properties
        product.Name = request.Name;
        product.Price = request.Price;
        // ... other properties

        await _dbContext.SaveChangesAsync(ct); // Audit interceptor triggers

        // Invalidate cache
        await _cacheService.RemoveAsync($"products:{id}", ct);
        await _cacheService.RemoveByPrefixAsync("products:list:", ct);

        _logger.LogInformation("Product {ProductId} updated successfully", id);
        return Result<Product>.Success(product);
    }
    catch (Exception ex)
    {
        _logger.LogError(ex, "Error updating product {ProductId}", id);
        return Result<Product>.Failure("An error occurred updating the product", 500);
    }
}
```
