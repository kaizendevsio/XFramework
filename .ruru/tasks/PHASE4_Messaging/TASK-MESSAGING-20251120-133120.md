# Task: Messaging Module VSA Migration

## Description

Migrate the **Messaging** module from CQRS/MediatR architecture to Vertical Slice Architecture (VSA). This module handles direct messaging functionality between users/entities within the system.

## Context

**Current Architecture:**
- Module location: `src/Modules/XFramework.Messaging/`
- Uses MediatR with 2 handlers:
  1. `CreateDirectMessageRequest` → `CreateDirectMessage` handler
  2. `UpdateMessageDirectRequest` → `UpdateMessageDirect` handler (in Query folder, likely misplaced command)
- Likely integrated with SignalR for real-time message delivery

**Target Architecture:**
- Create unified `IMessagingService` interface
- Implement `MessagingService` consolidating both handlers
- Remove MediatR dependency
- Update controllers/hubs to inject IMessagingService directly
- All service methods return `Result<T>`
