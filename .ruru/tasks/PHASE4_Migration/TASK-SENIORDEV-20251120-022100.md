# Task: StreamFlow Module VSA Migration

## Description

Migrate the StreamFlow module from CQRS/MediatR architecture to Vertical Slice Architecture (VSA) with direct service injection. Consolidate handler logic into a unified `StreamFlowService` that the SignalR hub can call directly, removing the MediatR layer while preserving all functionality including the Channels optimization from Phase 3.3.

## Current Architecture Analysis

**SignalR Hub**: [`MessageQueueHub.cs`](src/Modules/XFramework.StreamFlow/StreamFlow.Stream/Hubs/MessageQueueHub.cs)
- Currently injects `IMediator` and calls `_mediator.Send()`
- Methods: Invoke, InvokeResponse, Push, Subscribe, Register, Unsubscribe

**MediatR Handlers** (to be removed):
- [`PushMessageHandler.cs`](src/Modules/XFramework.StreamFlow/StreamFlow.Stream/Services/Handlers/Events/PushMessageHandler.cs) - Handles message distribution (FanOut, Direct, Topic)
- [`RegisterClientHandler.cs`](src/Modules/XFramework.StreamFlow/StreamFlow.Stream/Services/Handlers/Events/RegisterClientHandler.cs) - Handles client registration
- Additional handlers for Invoke, InvokeResponse, DequeueMessages

**Command/Query Entities** (to be removed):
- `PushMessageCmd`, `RegisterClientCmd`, `InvokeMethodQuery`, `InvokeMethodResponseCmd`, `DequeueMessagesCmd`

**Infrastructure to Preserve**:
- [`StreamFlowMessageQueue.cs`](src/Modules/XFramework.StreamFlow/StreamFlow.Core/Services/StreamFlowMessageQueue.cs) - Channels-based queue (Phase 3.3)
- [`StreamFlowProcessor.cs`](src/Modules/XFramework.StreamFlow/StreamFlow.Stream/Services/StreamFlowProcessor.cs) - Background service (Phase 3.3)
- [`ICachingService.cs`](src/Modules/XFramework.StreamFlow/StreamFlow.Core/Interfaces/ICachingService.cs) - Client tracking

## Example Service Method

```csharp
public async Task<Result<PushMessageResult>> PushMessageAsync(
    StreamFlowMessage message,
    HubCallerContext context,
    CancellationToken ct = default)
{
    try
    {
        // Check if Client is Registered
        var client = _cachingService.Clients
            .FirstOrDefault(x => x.Value.StreamId == context.ConnectionId);
            
        if (client.Value == null)
        {
            _logger.LogWarning("Unknown client. ConnectionId: {ConnectionId}", 
                context.ConnectionId);
            return Result<PushMessageResult>.Unauthorized("Client not registered");
        }

        // Execute message distribution based on exchange type
        switch (message.ExchangeType)
        {
            case MessageExchangeType.FanOut:
                await _hubContext.Clients.All.SendAsync(
                    message.CommandName, message, ct);
                break;
                
            case MessageExchangeType.Direct:
                await HandleDirectMessageAsync(message, client.Value, ct);
                break;
                
            case MessageExchangeType.Topic:
                await _hubContext.Clients.Group(message.Topic)
                    .SendAsync(message.CommandName, message, ct);
                break;
                
            default:
                return Result<PushMessageResult>.Failure(
                    $"Unsupported exchange type: {message.ExchangeType}", 400);
        }

        return Result<PushMessageResult>.Success(new PushMessageResult
        {
            MessageId = message.RequestId,
            Delivered = true
        });
    }
    catch (Exception ex)
    {
        _logger.LogError(ex, "Error pushing message. RequestId: {RequestId}", 
            message.RequestId);
        return Result<PushMessageResult>.Failure(
            "An error occurred processing the message", 500);
    }
}
```
