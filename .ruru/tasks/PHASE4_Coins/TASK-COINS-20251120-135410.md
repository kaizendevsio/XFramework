# Task: Coins Module VSA Migration (FINAL Phase 4 Module)

## Description

Migrate the **Coins** module from CQRS/MediatR architecture to Vertical Slice Architecture (VSA). This module handles blockchain operations, specifically Bitcoin bulk send functionality. **This is the 7th and FINAL backend module migration in Phase 4.**

## Context

**Current Architecture:**
- Module location: `src/Modules/XFramework.Coins/`
- Uses MediatR with 1 handler:
  1. `BulkSendCmd` → `BulkSendHandler` (Bitcoin bulk send operations)
- Controller: `BlockchainController` injects IMediator
- Appears to be experimental/blockchain-specific functionality

**Target Architecture:**
- Create unified `IBlockchainService` interface (or `ICoinService`)
- Implement `BlockchainService` consolidating the handler
- Remove MediatR dependency
- Update controller to inject service directly
- All service methods return `Result<T>`
