# Task: SmsGateway Module VSA Migration

## Description

Migrate the **SmsGateway** module from CQRS/MediatR architecture to Vertical Slice Architecture (VSA). This module handles SMS messaging functionality including sending, receiving, confirming, and scheduling SMS messages.

## Context

**Current Architecture:**
- Module location: `src/Modules/XFramework.SmsGateway/`
- Uses MediatR with 5 handlers:
  1. `ConfirmSmsMessageSentRequest` → `ConfirmSmsMessageSent` handler
  2. `CreateMessageReceived` handler
  3. `CreateSmsMessageRequest` → `CreateSmsMessage` handler
  4. `GetPendingSmsMessageListRequest` → `GetPendingSmsMessageListHandler` handler
  5. `GetScheduledSmsMessageListRequest` → `GetScheduledSmsMessageListHandler` handler
- Controller: `SmsGatewayNodeController` injects IMediator

**Target Architecture:**
- Create unified `ISmsService` interface
- Implement `SmsService` consolidating all 5 handlers
- Remove MediatR dependency
- Update controller to inject ISmsService directly
- All service methods return `Result<T>`
