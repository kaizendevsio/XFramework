# Task: Implement Batch Operations for Wallets Module

## Description

Implement high-performance batch operations for the Wallets module to handle bulk transaction processing, mass balance adjustments, and end-of-day reconciliation operations efficiently. Current implementation processes transactions individually, which is inefficient for bulk operations.

## Current Implementation Analysis

**Single Transaction Pattern** (IncrementWallet.cs, TransferWallet.cs):
- Each operation calls `dbContext.SaveChangesAsync()` individually
- No support for batch processing
- Inefficient for processing 100+ transactions
- Example: Processing 1000 wallet increments = 1000 separate DB round-trips

**Use Cases Requiring Batch Operations**:
- Bulk incentive distributions (1000+ wallets)
- End-of-day reconciliation
- Mass balance adjustments
- Promotional credit distribution
- Refund processing for multiple transactions
- Migration/data import operations

## Implementation Example

### Batch Increment Method
```csharp
public async Task<Result<BatchOperationResult>> BatchIncrementAsync(
    List<BatchIncrementRequest> requests, 
    CancellationToken ct = default)
{
    var stopwatch = Stopwatch.StartNew();
    var result = new BatchOperationResult();
    
    using var transaction = await _dbContext.Database.BeginTransactionAsync(ct);
    try
    {
        // Validate all requests first
        var walletIds = requests.Select(r => r.WalletId).Distinct().ToList();
        var wallets = await _dbContext.Set<Wallet>()
            .Where(w => walletIds.Contains(w.Id))
            .ToDictionaryAsync(w => w.Id, ct);
        
        var transactions = new List<WalletTransaction>();
        
        foreach (var request in requests)
        {
            if (!wallets.TryGetValue(request.WalletId, out var wallet))
            {
                result.Errors.Add(new BatchOperationError
                {
                    ItemIndex = requests.IndexOf(request),
                    ErrorMessage = $"Wallet {request.WalletId} not found"
                });
                continue;
            }
            
            // Update wallet balance
            wallet.Balance += request.Amount;
            
            // Create transaction record
            transactions.Add(new WalletTransaction
            {
                WalletId = wallet.Id,
                Amount = request.Amount,
                // ... other fields
            });
            
            result.SuccessCount++;
        }
        
        // Bulk insert all transactions
        await _dbContext.Set<WalletTransaction>().AddRangeAsync(transactions, ct);
        await _dbContext.SaveChangesAsync(ct);
        await transaction.CommitAsync(ct);
        
        result.TotalProcessed = requests.Count;
        result.Duration = stopwatch.Elapsed;
        
        _logger.LogInformation(
            "Batch increment completed: {Success}/{Total} in {Duration}ms",
            result.SuccessCount, result.TotalProcessed, result.Duration.TotalMilliseconds);
        
        return Result<BatchOperationResult>.Success(result);
    }
    catch (Exception ex)
    {
        await transaction.RollbackAsync(ct);
        _logger.LogError(ex, "Batch increment failed");
        return Result<BatchOperationResult>.Failure("Batch operation failed", 500);
    }
}
```

## Expected Performance Improvements

### Current Performance (Individual Operations)
- 1000 increments: ~10,000ms (10ms per operation × 1000)
- Database round-trips: 1000
- Transaction overhead: High (1000 transactions)

### Expected Performance (Batch Operations)
- 1000 increments: ~200-500ms (0.2-0.5ms per operation)
- Database round-trips: 3 (fetch wallets, insert transactions, update wallets)
- Transaction overhead: Low (1 transaction)
- **Performance improvement: 20-50x faster**

### Batch Size Recommendations
- Small batches (< 100 items): ~50-100ms
- Medium batches (100-500 items): ~200-300ms
- Large batches (500-1000 items): ~400-600ms
- Very large batches (> 1000 items): Split into chunks
