# Task: Community Module VSA Migration

## Description

Migrate the **Community** module from CQRS/MediatR architecture to Vertical Slice Architecture (VSA). This module handles community identity management and connection relationships between users/entities.

## Context

**Current Architecture:**
- Module location: `src/Modules/XFramework.Community/`
- Uses MediatR with 3 handlers:
  1. `CreateCommunityIdentityRequest` → `CreateCommunityIdentity` handler
  2. `UpdateCommunityIdentityRequest` → `UpdateCommunityIdentity` handler
  3. `GetCommunityConnectionListRequest` → `GetConnectionList` handler
- Manages community identities and connection relationships

**Target Architecture:**
- Create unified `ICommunityService` interface
- Implement `CommunityService` consolidating all 3 handlers
- Remove MediatR dependency
- Update controllers to inject ICommunityService directly
- All service methods return `Result<T>`
